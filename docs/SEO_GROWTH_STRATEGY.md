## Technical Implementation Guide

### For Every New Page Created

#### 1. Update Sitemap
```xml
<!-- Add to public/sitemap.xml -->
<url>
  <loc>https://yudezign.com/new-page</loc>
  <lastmod>2025-01-15</lastmod>
  <changefreq>monthly</changefreq>
  <priority>0.7</priority>
</url>
```

#### 2. Add SEO Component
```tsx
import SEO from '@/components/SEO';

export default function NewPage() {
  return (
    <>
      <SEO
        title="Page Title | YuDezign Custom Cabinets Houston"
        description="Meta description with target keyword, 150-160 chars"
        canonical="https://yudezign.com/new-page"
        ogImage="/images/new-page-og.jpg"
      />
      {/* Page content */}
    </>
  );
}
```

#### 3. Add Structured Data

For service pages, add Service schema:
```json
{
  "@context": "https://schema.org",
  "@type": "Service",
  "name": "Custom Kitchen Cabinets",
  "provider": {
    "@id": "https://yudezign.com/#organization"
  },
  "areaServed": {
    "@type": "City",
    "name": "Houston, TX"
  }
}
```

For FAQ pages, add FAQPage schema with questions and answers.

For blog posts, add Article schema with author, date, and images.

#### 4. Image Optimization
- WebP format
- Descriptive alt text with keywords
- Proper sizing and lazy loading
- Image schema where appropriate

#### 5. Internal Linking
- Link from navigation (if primary page)
- Add to footer (if important)
- Link from related pages
- Include in blog posts
