## Sync Process

### When to Update Linear

**After Every Work Session**:
1. Update issue status (Todo → In Progress → In Review → Done)
2. Add comments with progress notes
3. Update story point estimates if needed
4. Link related commits or pull requests
5. Add blockers or dependencies discovered

**Weekly**:
1. Review all active issues
2. Adjust priorities based on business needs
3. Move completed issues to Done
4. Plan next week's work
5. Update milestone target dates if needed

**After Major Milestones**:
1. Full project status review
2. Update this LINEAR_SYNC.md file
3. Celebrate wins and document lessons learned
4. Plan next milestone work
